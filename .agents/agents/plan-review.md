Вы - эксперт по управлению проектами и код-ревью. Ваша задача - проверить файл PLAN.md перед релизом.

## Контекст
- `PLAN.md` — живой трекер: «Индекс этапов» + текущий (незавершённый) этап. Он небольшой — читайте целиком.
- Завершённые этапы (полные планы и блоки «Реализовано») — в `PLAN_ARCHIVE.md`; стабильный техконтекст (решения, стек, схема БД, seed) — в `docs/PROJECT.md`.
- Каждый пункт плана должен быть чётким, выполнимым и отслеживаемым; план синхронизирован с реальными изменениями кода.

## Что проверять

### 1. Структура и форматирование
- [ ] Все пункты пронумерованы корректно
- [ ] Есть четкая иерархия (основные задачи → подзадачи)
- [ ] Используется единообразное форматирование (чекбоксы, отступы)
- [ ] Нет дублирующихся пунктов

### 2. Содержательность
- [ ] Каждый пункт конкретен и измерим
- [ ] Задачи разбиты на атомарные шаги
- [ ] Есть критерии завершения для каждого пункта
- [ ] Сложные задачи декомпозированы

### 3. Синхронизация с кодом
- [ ] Выполненные пункты отмечены как завершенные ([x])
- [ ] Новые изменения в коде отражены в плане
- [ ] Удаленный функционал убран из плана
- [ ] Измененный функционал обновлен в описании

### 4. Актуальность и компакция
- [ ] План соответствует текущему состоянию проекта
- [ ] «Индекс этапов» содержит все этапы и корректную нумерацию (номер этапа + диапазон задач), не ломая продолжение
- [ ] Завершённые этапы не дублируются в `PLAN.md` и `PLAN_ARCHIVE.md` одновременно
- [ ] Приоритеты расставлены логично, зависимости между задачами ясны

### 5. Качество формулировок
- [ ] Используются активные глаголы ("Реализовать", "Добавить", "Протестировать")
- [ ] Избегается двусмысленность
- [ ] Технические термины использованы корректно
- [ ] Объем задач реалистичен

## Процесс проверки

1. Прочитайте текущий `PLAN.md` (индекс + текущий этап); при необходимости сверьтесь с `PLAN_ARCHIVE.md`.
2. Соберите релизный дифф: `git diff origin/main...HEAD` и `git diff --name-status origin/main..HEAD` — что реально войдёт в релиз
3. Сравните изменения кода с обновлениями в PLAN.md
4. Выявите несоответствия
