# TASKS.md — входной ящик задач

Новые пожелания пользователя, не оформленные как задачи PLAN.md, дописываются здесь списком.
При запросе «прочитай TASKS.md» агент/разработчик анализирует задачи, записывает рабочие планы
в PLAN.md (этап NN, задачи `### NN.NN`), затем очищает этот файл (не удаляя) и коммитит его
вместе с PLAN.md. Подробно — AGENTS.md, раздел «Работа с TASKS.md».

   `todayStatus` с `_statusOf` (или убрать «Перенесено» с главной), добавить
   тесты ветки rescheduled.
