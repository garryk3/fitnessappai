# FitnessAppAI

Офлайн-приложение для планирования и отслеживания спортивных тренировок. Android 12+, Material 3, локализация — русский.

Возможности: встроенная база упражнений с анимациями и схемой мускулатуры, конструктор программ (1–7 дней, привязка к дням недели), выполнение тренировок с таймером отдыха, план недели со статусами, статистика и графики прогресса, профиль с замерами тела и противопоказаниями, ручной экспорт/импорт БД.

Стек: Flutter / Dart, `drift` (SQLite), `signals`, `go_router`, `fl_chart`.

Полное описание — в [README приложения](fitnessappai/README.md).
