# FitnessAppAI

Офлайн-приложение для планирования и отслеживания спортивных тренировок.
Android 12+, Material 3, полностью на русском языке.

## Скачать

Последняя версия APK: [FitnessAppAI latest](https://github.com/garryk3/fitnessappai/releases).

## Что это за приложение

FitnessAppAI — это персональный тренер в кармане. Приложение помогает составить
программу тренировок, выполнять их с правильным таймером и звуковыми сигналами,
отслеживать прогресс по весам, объёмам тела и нагрузке на мышцы. Всё работает
полностью офлайн — никаких серверов, никакой регистрации, ваши данные всегда на
вашем устройстве.

## Возможности

### Тренировки

- **Выполнение тренировок** с фиксацией каждого подхода: повторения, вес,
  время удержания, дистанция — в зависимости от типа упражнения.
- **Таймер отдыха** между подходами с обратным отсчётом и звуковым сигналом
  по окончании.
- **Разминка** с обратным отсчётом перед каждой тренировкой (настраивается
  в параметрах программы).

- **Таймер удержания планки** — большой таймер с кнопкой «Начать», считает
  фактическое время. Когда планка превышает цель — счётчик подсвечивается.
- **Подходы с двух сторон** — для упражнений на одну руку/ногу каждая серия
  разбивается на левую и правую сторону с отдыхом между ними.
- **Предыдущая тренировка** — во время выполнения показываются результаты
  прошлой тренировки для этого упражнения, чтобы вы знали, к чему стремиться.
- **Экран итогов** — после завершения тренировки: количество подходов,
  длительность, ссылка на прогресс.

### Программы

- **Конструктор программ** на 1–7 дней с привязкой к конкретным дням недели.
- **Основной и альтернативный наборы** упражнений для каждого дня — выбирайте,
  какой вариант выполнять, прямо во время тренировки.
- **Параметры упражнений**: количество подходов, повторения, вес, время,
  дистанция, отдых — всё настраивается отдельно для каждого упражнения.
- **Редактор упражнений программы** с drag-and-drop перетаскиванием,
  интерактивной схемой мускулатуры и валидацией перед сохранением.

### Упражнения

- **Встроенная база** из 15+ упражнений с описанием техники, ошибок и
  мышечных групп.
- **Четыре типа**: силовые (с весом), собственный вес, планка (удержание),
  бег (дистанция + время) — для каждого типа свои поля ввода и статистика.
- **Анимации упражнений** — каждое упражнение сопровождается визуальной
  подсказкой.
- **Поиск и фильтры** — по названию, по типу, по «только свои» упражнения.
- **Создание своих упражнений** с описанием, техникой, частыми ошибками,
  маппингом мышц, тегами противопоказаний, загрузкой своих изображений и
  анимаций.
- **Интерактивная схема мышц** — при добавлении упражнений в программу
  на экране в реальном времени подсвечиваются целевые мышцы на SVG-диаграмме
  тела (спереди и сзади) с градиентом интенсивности.

### План недели

- **Еженедельный план** с автоматическими статусами: запланировано, выполнено,
  перенесено, пропущено.
- **Быстрый старт** — одна кнопка для запуска ближайшей запланированной
  тренировки.
- **Навигация по неделям** — просмотр прошлых и будущих недель.
- **Перенос и пропуск** тренировок одним касанием.

### Прогресс

- **Статистика за неделю, месяц, год**: количество тренировок, дистанция,
  время планки.
- **Графики прогресса** по каждому упражнению — вес, повторения, время,
  дистанция (в зависимости от типа).
- **Нагрузка на мышцы** — интерактивная SVG-диаграмма тела с цветовой
  интенсивностью: видно, какие мышцы проработаны лучше, а какие требуют
  внимания. Топ-5 мышц по проценту нагрузки.
- **Детализация по дням** — нажмите на столбец диаграммы тренировок, чтобы
  увидеть все подходы за этот день.

### Замеры тела

- **10 метрик**: рост, вес, шея, грудь, талия, бёдра, бицепс, предплечье,
  бедро, икры.
- **Графики по каждой метрике** с фильтрацией по году.
- **История замеров** с датами и возможностью удаления.

### Противопоказания

- **8 категорий**: колени, спина, шея, плечи, локти, запястья, сердце,
  беременность.
- **Системные предупреждения**: вы задаёте свои ограничения один раз, и
  приложение автоматически:
  - показывает предупреждения на карточках упражнений, которые вам
    противопоказаны;
  - подсвечивает конфликтующие теги на странице упражнения;
  - перед началом тренировки показывает диалог со списком опасных упражнений
    с возможностью «Больше не показывать для этой программы».

### Звуки

- **Звук окончания таймера** — настраиваемый: можно выбрать свой звуковой
  файл или оставить стандартный.
- **Звук напоминания** — Android-уведомления о тренировочных днях с
  собственным звуковым файлом.

### Настройки

- Переключение **светлой и тёмной темы**.
- Настройка звуковых сигналов (выбор файла, сброс на стандартный).
- **Проверка обновлений** через GitHub Releases — приложение сообщает о
  новой версии и ведёт на страницу загрузки.

### Синхронизация

- **Экспорт базы данных** — сохранение файла или отправка через системный
  «Поделиться».
- **Импорт базы данных** — загрузка файла с другого устройства, валидация
  и замена текущей БД.
- Интерфейс рассчитан на будущую облачную синхронизацию.

### Профиль

- Отображение последних замеров тела в виде карточки.
- Переход к противопоказаниям.
- Ссылки на настройки и информацию о приложении.

## Чем отличается от аналогов

| Возможность | FitnessAppAI | Типичные приложения |
|---|---|---|
| **Противопоказания** | Системные: задали ограничения один раз — предупреждения везде: в каталоге, в деталях, перед тренировкой | Нет или ручные пометки на каждом упражнении |
| **Схема мышц** | Интерактивная SVG-диаграмма с градиентом интенсивности и пропорциями, обновляется в реальном времени | Статичные картинки или нет |
| **Таймер отдыха** | Считает по реальному времени: даже если экран погас, отсчёт корректен | Сбрасывается при блокировке экрана |
| **Двусторонние упражнения** | Каждый подход разбивается на лево/право с отдыхом между сторонами | Левая и правая сторона как один подход |
| **Альтернативные наборы** | Два варианта упражнений для каждого дня, выбор — во время тренировки | Только один набор |
| **Замеры тела** | 10 метрик с графиками и фильтрацией по годам | Обычно только вес |
| **Профиль мышечной нагрузки** | Автоматический расчёт из истории тренировок, визуализация на диаграмме тела | Нет |
| **Офлайн-архитектура** | Все данные на устройстве, экспорт/импорт файла БД | Облачные серверы, регистрация |
| **Создание упражнений** | Полный редактор: описание, техника, ошибки, мышцы, противопоказания, анимация, флаги | Базовое добавление |

## Стек технологий

- **Flutter / Dart** — кроссплатформенный UI-фреймворк
- **drift** — типобезопасный ORM для SQLite
- **signals** — реактивное управление состоянием
- **go_router** — декларативная навигация
- **fl_chart** — графики и диаграммы
- **flutter_local_notifications** — напоминания о тренировках
- **wakelock_plus** — удержание экрана во время тренировки
- **audioplayers** — воспроизведение звуковых сигналов

для загрузчика.
